Méthodes rigoureuses de cotation fonctionnelle

Éliminez les approximations et erreurs vectorielles de signe dans vos boucles d'assemblage.

1

Pire des cas (Worst-Case)

Cumul arithmétique absolu des tolérances. Garantit l'interchangeabilité totale et le respect des jeux fonctionnels pour 100 % des composants, même dans les configurations géométriques les plus défavorables.

IT_total = ∑ IT_i
J_min,WC = J_nom + ∑ (± ei/es)
2

Statistique quadratique (RSS à 3σ)

Fondée sur la loi normale et le théorème central limite. Permet d'élargir les tolérances individuelles d'usinage pour réduire les coûts de fabrication tout en maintenant un risque statistique maîtrisé (< 0.27 % hors bornes).

IT_total,RSS = √(∑ IT_i²)
J_min,RSS = J_moy - IT_total,RSS / 2
3

Analyse de contribution de Pareto

Identifie immédiatement les maillons pénalisants dont la variance domine l'assemblage ($C_i = \frac{IT_i^2}{\sum IT_k^2} \times 100$). Permet de focaliser l'effort de tolérancement là où l'impact géométrique est le plus fort.

4

Évaluation de conformité Go / No-Go

Confrontation directe aux jeux cibles minimal et maximal ($J_{\min,\text{cible}}$, $J_{\max,\text{cible}}$) avec calcul automatique des marges de sécurité pour la validation de vos revues de conception.

Référentiels normatifs intégrés (ISO GPS)

Accès direct aux abaques de tolérances sans consultation de tables manuelles.

🔧 Système d'ajustements ISO 286

Lookup automatique des écarts limites ($ES, EI, es, ei$) par paliers de diamètre nominal jusqu'à 500 mm. Détermination immédiate de la nature de la liaison cylindrique :

  • ✓ Ajustement avec jeu (ex: H7/g6, H8/f7, D10/h6)
  • ✓ Ajustement incertain / transition (ex: H7/k6, H7/m6, H7/js6)
  • ✓ Ajustement avec serrage (ex: H7/p6, P9/h6)

📐 Tolérances générales ISO 2768-1 & ISO 22081

Tables des tolérances générales d'usinage par classes de précision (fine f, moyenne m, grosse c, très grosse v) pour les dimensions linéaires, chanfreins et angles.

Veille normative : Transition didactique vers la norme ISO 22081:2021 pour le tolérancement géométrique généralisé par profil de surface avec système de référence.

Démarrage et utilisation

CotaStack est une application Python / Streamlit légère, autonome et respectueuse de la confidentialité de vos données de conception.

💻 Exécution en local (Python ≥ 3.11)

# 1. Cloner le dépôt
git clone https://github.com/toma-e/CotaStack.git
cd CotaStack

# 2. Créer l'environnement virtuel et installer les dépendances
uv venv && uv pip install -r requirements.txt

# 3. Lancer l'application web Streamlit
streamlit run app.py

🧪 Suite de tests automatisés (100% couverture backend)

pytest --cov=backend --cov-report=term-missing

L'application s'ouvre automatiquement dans votre navigateur par défaut à l'adresse http://localhost:8501.
